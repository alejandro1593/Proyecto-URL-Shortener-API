 ¿QUÉ ES ESTE PROYECTO?
=============================================================================

Es una API REST (backend) que permite:

1. ACORTAR URLs largas
   - Transformas un link largo como:
     https://www.ejemplo.com/productos/categoria/tecnologia/laptops/gaming?color=rojo&precio=500-1000&orden=precio
   - En uno corto como:
     https://tudominio.com/abc123

2. REDIGIRIGIR automáticamente
   - Cuando alguien visita tudominio.com/abc123
   - El sistema lo redirige al link original
   - Esto ocurre en menos de 100ms

3. TRACKEAR analytics (estadísticas)
   - Cuántas veces se hizo clic en cada URL
   - Desde qué países/países
   - Qué dispositivos usaron (móvil, PC, tablet)
   - Cuándo se visitaron (por día, semana, mes)


 ¿PARA QUÉ SIRVE?
=============================================================================

CASOS DE USO REALES:

1. MARKETING Y REDES SOCIALES
   - Las URLs largas se ven feas en Twitter/Instagram
   - Con URL corta, el contenido es más limpio
   - Ejemplo: https://tudominio.com/promo2024 → Página de oferta

2. EMAIL MARKETING
   - En emails, las URLs cortas generan más clics
   - Puedes trackear cuántos abrieron tu email

3. ANÁLISIS DE DATOS
   - Saber qué contenido es más popular
   - Medir el rendimiento de campañas publicitarias
   - Tomar decisiones basadas en datos reales

4. APIs PÚBLICAS
   - Otras empresas pueden integrar tu servicio
   - Ejemplo: una app móvil que acorta URLs automáticamente

5. GESTIÓN DE ENLACES
   - Organizar cientos de URLs por categorías
   - Eliminar links rotos fácilmente
   - Crear URLs con expiración (por ejemplo: links de descarga temporales)

 FLUJO BÁSICO DEL SISTEMA
=============================================================================

USUARIO CREA UNA CUENTA
          ↓
USUARIO PEGA UNA URL LARGA
          ↓
SISTEMA GENERA CÓDIGO CORTO (ej: abc123)
          ↓
SE GUARDA EN BASE DE DATOS:
   - Código corto: abc123
   - URL original: https://url-muy-larga...
   - ID del usuario: 123
   - Fecha: 2024-01-15
          ↓
USUARIO COMPARTE EL LINK CORTO
          ↓
CUANDO ALGUIEN VISITA EL LINK:
   - Se busca en la base de datos
   - Se registra el clic (analytics)
   - Se redirige a la URL original

 APRENDIZAJES CLAVE
=============================================================================

Al completar este proyecto aprenderás:

1. DISEÑO DE APIs REST
   - Endpoints bien organizados
   - Métodos HTTP correctos (GET, POST, DELETE)
   - Códigos de estado (200, 201, 400, 401, 404, 500)
   - Paginación y filtrado

2. AUTENTICACIÓN MODERNA
   - JWT (JSON Web Tokens)
   - OAuth2 (login con Google/GitHub)
   - Bcrypt para contraseñas
   - Roles de usuario

3. BASE DE DATOS
   - Modelado de esquemas
   - Queries optimizadas
   - Índices para performance
   - Migraciones

4. CACHING CON REDIS
   - Qué es y por qué es rápido
   - Cuándo cachear vs consultar BD
   - Estrategias de invalidación

5. TESTING
   - Tests unitarios (funciones aisladas)
   - Tests de integración (API completa)
   - Cobertura de código
   - Mocking

6. DEVOPS BÁSICO
   - Docker (containers)
   - CI/CD (deploy automático)
   - Variables de entorno
   - Deploy en la nube (Railway/Render)
